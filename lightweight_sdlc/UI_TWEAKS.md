# UI Tweaks

Use this list for small visual, layout, accessibility, and copy refinements the user requested or explicitly approved. These are not product features.

Promote work into `BACKLOG.md` and the Kanban feature flow when it affects behavior, data, navigation, permissions, persistence, sharing, backup/restore, or otherwise needs planned UAT.

All tweaks must follow `PRODUCT_VISION.md` and `DESIGN_SYSTEM.md`. Reusable tokens, components, or patterns belong in the design system rather than a one-off implementation.

Before marking a tweak complete:

- Inspect the affected surface and relevant states.
- Verify applicable contrast, labels, focus, touch target, dynamic type/zoom, and reduced-motion behavior.
- Run validation appropriate to the changed files.
- Record the result below and wait for explicit user approval before commit.
